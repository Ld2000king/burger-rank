# BunRank — דירוג ההמבורגרים שלנו

PWA לדירוג המבורגרים: טבלת דירוג, ציון 1–10 לטעם / קציצה / לחמנייה / תוספות / תמורה למחיר, תמונות, מצב כהה, מסך פתיחה של המבורגר שנפתח לשכבות, שאלון פתיחה ואנימציית נגיסה.

- סטטי לגמרי (HTML/CSS/JS), בלי build.
- הנתונים נשמרים במכשיר (IndexedDB). בתוך Claude artifact הטבלה משותפת דרך `claude.use("db")`.
- איפוס מקומי: הוסיפו `?reset` לכתובת.
