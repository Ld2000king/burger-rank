# Ranks — מדרגים הכול עם החברים

ענף `ranks`: אותה אפליקציה כמו ב-`main` (BunRank), רק כללית. כל קבוצה בוחרת נושא — המבורגרים, פיצה, סושי, בתי קפה, מסעדות, סרטים, סדרות, משחקים, ספרים, מסלולים, או נושא משלה עם עד 5 קטגוריות ציון. כל חבר מדרג, והממוצע של כולם קובע את הפודיום.

- סטטי לגמרי (HTML/CSS/JS), בלי build.
- נושאים וקטגוריות: `topics.js`.
- סנכרון בין חברים: Firebase (Firestore + Anonymous Auth). ההגדרות ב-`firebase-config.js`, חוקי האבטחה ב-`firestore.rules`. כל עוד הקובץ ריק, האפליקציה עובדת על המכשיר בלבד.
