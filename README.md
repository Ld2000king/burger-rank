# BunRank — דירוג מקומות המבורגר עם חברים

PWA: יוצרים קבוצה, מזמינים חברים עם קוד בן 6 תווים, כל אחד מדרג מקומות (טעם / קציצה / לחמנייה / תוספות / תמורה למחיר), והממוצע של כולם קובע את הפודיום — מקום ראשון, שני ושלישי.

- סטטי לגמרי (HTML/CSS/JS), בלי build. מתארח ב-GitHub Pages.
- סנכרון בין חברים: Firebase (Firestore + Anonymous Auth). ההגדרות ב-`firebase-config.js`, חוקי האבטחה ב-`firestore.rules`.
- כל עוד `firebase-config.js` ריק, האפליקציה עובדת על המכשיר בלבד.
